# Smart Academic Management System (SAMS)

A full-stack web application developed using Django to simplify academic management for students, faculty, and administrators.

## Live Demo

🌐 https://sams-s54g.onrender.com/

## Features

### Student
- Secure Login
- View Attendance
- View Study Materials
- Assignment Management
- SGPA & CGPA Calculator
- No Dues Status

### Faculty
- Upload Study Materials
- Manage Assignments
- Mark Attendance
- Student Management

### Admin
- Manage Users
- Manage Departments
- Academic Management
- System Administration

## Installation

Clone the repository

```bash
git clone https://github.com/Riyas-n-s/SAMS.git
```

Move into the project

```bash
cd SAMS
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Start the development server

```bash
python manage.py runserver
```

Open:

```
http://127.0.0.1:8000/
```
